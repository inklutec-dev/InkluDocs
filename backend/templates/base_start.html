{# ────────────────────────────────────────────────────────────────────────── base_start.html — Grundgerüst der STARTSEITE und der LOGIN-KARTEN (02.09.2026). Doku: docs/STARTSEITE.md, Übersicht docs/SEITENGERUEST.md Warum es das gibt (Steve + Michael, 02.09.2026): Die Wurzel inkludocs.de war bis heute die Anmeldemaske. Wer InkluDocs nicht kannte, erfuhr dort nicht, was das Werkzeug tut, für wen es ist und was es kostet — und Suchmaschinen sahen nur „Anmeldung“. Jetzt ist / eine echte Startseite (start.html), die Anmeldung wohnt unter /login. Optik: BEWUSST OHNE die App-Seitenleiste von base_oeffentlich.html. Eine Startseite muss erklären und überzeugen, dafür braucht sie die ganze Breite und einen ruhigen Kopf. Stattdessen eine schlanke Kopfzeile in Navy: Marke links, rechts Preise / Kontakt / Über uns / Anmelden und der orangefarbene Knopf „Kostenlos starten“. Die Kopfzeile ist SERVERSEITIG gerendert (kein dashboard.js): Sie steht ohne JavaScript im HTML, für Suchmaschinen wie für Prüfskripte. Darunter main#main, unten dieselbe Fußzeile wie alle öffentlichen Seiten (_fusszeile.html, eine Quelle). Die vier Login-Karten (/login, /register, /forgot, /reset) erweitern ebenfalls dieses Gerüst: Sie behalten ihr zentriertes Karten-Layout (.auth-container), bekommen aber Kopf- und Fußzeile geschenkt und verlieren ihre bisher von Hand getippte .legal-footer. Kontakt und Über uns stehen in der Kopfzeile — deshalb rechtslinks() ohne mit_kontakt. Barrierefreiheit (BITV 2.0 / WCAG 2.2): Skip-Link als erstes Element, Landmarken header / nav / main / footer (die einzige nav der Seite braucht keinen aria-label; die Marke heißt sichtbar „InkluDocs“ und braucht keinen), genau eine H1 je Seite (Thema der Seite, nicht die Marke — die steht in der Kopfzeile), aria-current="page" auf dem aktiven Kopfzeilen-Eintrag (das einzige ARIA im Gerüst — HTML hat dafür nichts Eigenes; Steve 03.09.2026: ARIA nur wo nötig), tabindex="-1" auf main, damit der Sprunglink in Safari den Fokus wirklich setzt, sichtbarer Fokus, Zielgrößen ≥ 44 px (start.css). Staging-Hinweis nur im Fenstertitel (base.html), nie in der H1. Suchmaschinen: Block `seo` nimmt Meta-Beschreibung, canonical, Open Graph und JSON-LD der jeweiligen Seite auf. Auf Staging setzt das Gerüst zusätzlich noindex/nofollow, damit die Testumgebung nie im Index landet. Blöcke: title Fenstertitel (base.html hängt auf Staging „(Testumgebung)“ an) seo Meta-/Link-Elemente im (Beschreibung, canonical, OG …) main_class Zusatzklasse für main (Login-Karten: start-main-auth) main Seiteninhalt page_script Seiten-JavaScript (die Karten bringen ihres selbst mit) Template-Variable nav_aktiv (Route setzt sie): Pfad des aktiven Eintrags der Kopfzeile, z.
